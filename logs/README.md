## Training Log Files

### CSV Format
Each model has a CSV log with training history:

**Columns**:
- `epoch` - Training epoch number
- `accuracy` - Training accuracy
- `loss` - Training loss
- `auc_ovr` - Training AUC (one-vs-rest)
- `overall_precision` - Training precision
- `overall_recall` - Training recall
- `val_accuracy` - Validation accuracy
- `val_loss` - Validation loss
- `val_auc_ovr` - Validation AUC
- `val_overall_precision` - Validation precision
- `val_overall_recall` - Validation recall

**Example**:
```csv
epoch,accuracy,loss,auc_ovr,overall_precision,overall_recall,val_accuracy,val_loss,val_auc_ovr,val_overall_precision,val_overall_recall
0,0.613,0.965,0.855,0.698,0.534,0.793,0.724,0.945,0.935,0.536
1,0.799,0.531,0.944,0.837,0.756,0.856,0.460,0.969,0.911,0.779
...
```

### Loading Logs in Python

```python
import pandas as pd

# Load training log
log = pd.read_csv('logs/classification/ConvNeXtBase_training_log.csv')

# Plot training history
import matplotlib.pyplot as plt

plt.plot(log['epoch'], log['accuracy'], label='Train')
plt.plot(log['epoch'], log['val_accuracy'], label='Validation')
plt.xlabel('Epoch')
plt.ylabel('Accuracy')
plt.legend()
plt.show()
```

## Generating Visualizations

Visualizations are automatically generated when running:

```bash
# Generate all plots
jupyter notebook notebooks/evaluate_all_models.ipynb
```

Or manually:
```python
import pandas as pd
import matplotlib.pyplot as plt

# Load all logs
models = ['ConvNeXt', 'ResNet152V2', 'DenseNet201', 'EfficientNetV2S', 'VGG16']
logs = {name: pd.read_csv(f'logs/classification/{name}_training_log.csv') 
        for name in models}

# Plot comparison
for name, log in logs.items():
    plt.plot(log['epoch'], log['val_accuracy'], label=name)
plt.legend()
plt.xlabel('Epoch')
plt.ylabel('Validation Accuracy')
plt.title('Model Comparison')
plt.savefig('logs/classification/comparison.png')
```

## Analyzing Training

### Check for Overfitting
```python
log = pd.read_csv('logs/classification/ConvNeXtBase_training_log.csv')

# Compare train vs validation
final_train_acc = log['accuracy'].iloc[-1]
final_val_acc = log['val_accuracy'].iloc[-1]
gap = final_train_acc - final_val_acc

if gap > 0.05:
    print(f"⚠️ Possible overfitting: {gap*100:.1f}% accuracy gap")
```

### Find Best Epoch
```python
log = pd.read_csv('logs/classification/ConvNeXtBase_training_log.csv')

# Find epoch with best validation accuracy
best_epoch = log['val_accuracy'].idxmax()
best_val_acc = log['val_accuracy'].max()

print(f"Best epoch: {best_epoch} with {best_val_acc*100:.2f}% val accuracy")
```

### Training Statistics
```python
log = pd.read_csv('logs/classification/ConvNeXtBase_training_log.csv')

print(f"Total epochs: {len(log)}")
print(f"Final train accuracy: {log['accuracy'].iloc[-1]*100:.2f}%")
print(f"Final val accuracy: {log['val_accuracy'].iloc[-1]*100:.2f}%")
print(f"Best val accuracy: {log['val_accuracy'].max()*100:.2f}%")
print(f"Final loss: {log['val_loss'].iloc[-1]:.4f}")
```

## Cleanup

To save disk space:

```bash
# Keep only final logs, remove intermediate checkpoints
rm -rf logs/classification/*/train/
rm -rf logs/classification/*/validation/

# Keep only CSV logs and final visualizations
find logs/classification/ -type f -name "*.tfevents.*" -delete
```
